Comandos

Todo lo que puedes hacer

Disponibles como comandos slash / y de texto con tu prefijo (por defecto sk!).

/ajustes
Ver la configuración actual del bot en el servidor.
/ping
Comprueba la latencia del WebSocket y estado del bot.
/invite
Enlace oficial para invitar a SkullBoard a tu servidor de Discord.
/dashboard
Enlace a la web oficial y panel de recursos de SkullBoard.
/notify
Activa o desactiva tus notificaciones personales por DM.
Ver parámetros ▾
estadoopcionalon / off
Sin valor muestra tu estado actual. on activa las alertas, off las desactiva.
/help
Lista completa de comandos organizados por categorías.
/top
Muestra los mensajes con más reacciones 💀 de todo el servidor.
/stats
Estadísticas detalladas de un usuario en el skullboard.
Ver parámetros ▾
usuarioopcionalmiembro
Usuario a consultar. Si se omite, muestra tus estadísticas personales.
/random
Obtén un mensaje destacado al azar del tablón de honor.
/ignored
Lista los canales de texto actualmente excluidos del skullboard.
/leaderboard
Top 10 usuarios con más calaveras 💀 acumuladas en el servidor.
/server_stats
Métricas y estadísticas globales de actividad del skullboard.
/top_month
Los mejores mensajes destacados del mes en curso.
/top_year
Los mejores mensajes destacados de todo el año actual.
/set_channel Admin
Define el canal de texto donde se publicarán los mensajes destacados.
Ver parámetros ▾
channelobligatoriocanal de texto
Canal destino del skullboard.
/set_min Admin
Establece el mínimo de reacciones 💀 para publicar un mensaje.
Ver parámetros ▾
cantidadobligatorionúmero ≥ 1
Cantidad requerida de reacciones de calavera.
/prefix Admin
Cambia el prefijo para los comandos de texto (por defecto sk!).
Ver parámetros ▾
nuevo_prefijoobligatoriotexto (máx 10)
Nuevo prefijo para invocar comandos de texto.
/ignore Admin
Excluye un canal de texto para que sus mensajes no se cuenten.
Ver parámetros ▾
canalobligatoriocanal de texto
Canal que no participará en el skullboard.
/unignore Admin
Reincorpora un canal previamente ignorado al skullboard.
Ver parámetros ▾
canalobligatoriocanal de texto
Canal a habilitar nuevamente.
/setup_pin Admin
Configura el fijado automático (Auto-Pin) a partir de un umbral.
Ver parámetros ▾
umbralobligatorionúmero ≥ 0
Calaveras para auto-pin. Especificar 0 desactiva el auto-pin.
/resync Admin
Recuenta las 💀 reales del servidor y limpia duplicados o borrados.
/reset Dueño
Reinicia el tablón del servidor (exclusivo para el propietario).
