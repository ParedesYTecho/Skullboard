# Operation: Ingestion (SecondBrain)

## Adding a Source
1. Place candidate material in `inbox/` or register reference in `config/sources.yaml`.
2. Inspect for credentials, secrets, or private data.
3. Add entry to `catalog/sources.jsonl`.
4. Compile distilled content into appropriate `wiki/` markdown file.
5. Record compiled page in `catalog/pages.jsonl`.
